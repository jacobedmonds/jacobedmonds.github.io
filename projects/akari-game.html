Akari Puzzle Game

JavaFX desktop implementation of the Akari / Light Up logic puzzle with interactive lamp placement, puzzle validation, and multi-puzzle navigation using MVC architecture.

← Back to Home GitHub Repo

Project Overview

This project is an interactive desktop version of the Akari logic puzzle, also known as Light Up. Players place lamps on a grid to illuminate every corridor cell while satisfying numbered wall clues and preventing lamps from shining directly on one another.

Core Features

  • Interactive JavaFX puzzle board with clickable cells
  • Lamp placement and removal during gameplay
  • Automatic illumination logic across rows and columns
  • Validation for clue satisfaction and illegal lamp conflicts
  • Multiple built-in puzzles with Previous, Next, Random, and Reset controls
  • Puzzle completion detection with solved-state feedback

Architecture

The application follows a Model-View-Controller design. The model manages puzzle state and game-rule validation, the view renders the JavaFX interface, and the controller handles user actions such as puzzle navigation and board interaction.

Implementation Details

  • Used object-oriented Java interfaces and implementations to separate puzzle, model, controller, and view logic
  • Implemented observer-based updates so the UI responds to model changes
  • Represented puzzles as two-dimensional integer arrays mapped to clue, wall, and corridor cell types
  • Checked puzzle completion by verifying illuminated corridors, satisfied clues, and legal lamp placement

  • Applying MVC architecture in a larger Java project
  • Using the Observer Pattern to synchronize UI and application state
  • Writing rule-validation logic for a grid-based puzzle game
